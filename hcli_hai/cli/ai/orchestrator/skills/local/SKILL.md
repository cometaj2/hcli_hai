# Local tree
Use this when the goal is about the current directory, this folder, or the local repo.
Do not summarize until the tree has been observed.

- First task: print the working directory.
- Next task: list that directory. It depends on the working-directory task.
- Next tasks: read the files the listing named, with cat, head, or grep. One file, or one narrow grep, per task.
- A summary task must depend on those reads. Its acceptance is the summary of observed file contents, not a guess.
- Do not plan a clone if the files are already here.
