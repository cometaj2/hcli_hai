# Git
Use this when the goal is about a repository, branch, or commit.

- Prefer read-only tasks: status, log, diff, remote show.
- Do not plan commit, push, reset, or rebase unless the goal explicitly asks for that write.
- A diff or log task depends on knowing which repo. If the path is not given, the first task is the working directory.
- Acceptance is the observed git output, not an assumed history.
